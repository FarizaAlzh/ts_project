# AI Agent: Автоматизированный аудит технических заданий

### Идея проекта
Разработала систему на базе ИИ-агентов, которая помогает компаниям мгновенно анализировать технические задания.
Автоматизировать самый трудоемкий этап в IT-разработке: первичный анализ и аудит технической документации.

Эта система на базе CrewAI, созданная для автоматизации анализа ТЗ 
Система имитирует работу целого отдела аналитики: она берет на вход "сырой" PDF-файл и превращает его в структурированный отчет с оценкой рисков,
планом MVP и техническими рекомендациями.

Цель проекта: Показать, как ИИ-агенты могут заменить рутинный ручной аудит документации, экономя время менеджерам и техлидам.

---

### Технологический стек
Я использовала библиотеку **CrewAI**, которая позволяет создавать не просто чат-бота, а «умных сотрудников»

* **Language:** Python
* **Framework:** CrewAI 
* **LLM:** Llama-3 через Groq API (высокая скорость работы и точность анализа + бесплатная)
* **PDF Processing:** PyPDF2 (входные данные)
* **Reporting:** FPDF (автоматическая генерация PDF-отчетов)
  
---
### Архитектура системы (как это работает)
В проекте задействованы два специализированных агента, работающих последовательно:

* **Business Analyst Agent:** Исследует ТЗ на предмет бизнес-рисков, определяет целевую аудиторию и выделяет ключевые функции для MVP
* **Technical Lead Agent:** На базе выводов аналитика строит архитектурный план, оценивает сложность реализации и подбирает стек технологий

### Реализация
Мой подход заключался в создании конвейера, который превращает хаос из документов в четкую стратегию:

* **Архитектура агентов:** Я настроила CrewAI, где каждый агент имеет свою «личность». Аналитик фокусируется на бизнесе, а Техлид — на реализации. Это исключает поверхностные ответы
* **Обработка PDF:** Я написала модуль на Python, который очищает текст из PDF и подает его агентам порциями, чтобы не превышать лимиты модели и сохранять контекст
* **Автоматизация отчетности:** Реализовала функцию, которая берет финальный ответ агентов и мгновенно верстает его в PDF-файл.Теперь руководителю не нужно даже открывать код,он просто забирает готовый документ из папки outputs

### 🚀 Как запустить проект
Если вы хотите проверить работу лично:
1. Склонируйте репозиторий.
2. Создайте файл `.env` и вставьте ваш `GROQ_API_KEY`.
3. Установите библиотеки: `pip install -r requirements.txt`.
4. Положите PDF в папку `inputs` и запустите `python3 app.py`.
